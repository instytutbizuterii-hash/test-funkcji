JAK URUCHOMIĆ:

1. Otwórz plik index.html dwuklikiem.
2. Gotowe — nie trzeba nic instalować.

GITHUB PAGES:

1. Wrzuć wszystkie cztery pliki z tego katalogu do repozytorium.
2. W GitHub otwórz Settings > Pages.
3. W sekcji Build and deployment wybierz Deploy from a branch.
4. Wybierz gałąź main i katalog /(root), a następnie Save.

Pliki:
- index.html — struktura strony,
- style.css — wygląd i wersja mobilna,
- script.js — działanie karuzeli,
- README.txt — ta instrukcja.

Zdjęcia produktów są pobierane z internetu, dlatego do pełnego testu
potrzebne jest połączenie z siecią.
