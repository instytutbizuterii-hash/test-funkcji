# Lunéa — mobilna strona produktu

Statyczna strona produktu z interaktywną lupą obsługiwaną dotykiem, myszką
i klawiaturą.

## Uruchomienie

Otwórz plik `index.html` w przeglądarce. Projekt nie wymaga instalowania
pakietów ani procesu budowania.

## GitHub Pages

1. Prześlij całą zawartość tego folderu do głównego katalogu repozytorium.
2. W ustawieniach repozytorium otwórz **Pages**.
3. Wybierz publikację z gałęzi, na której znajdują się pliki, oraz katalog `/root`.
